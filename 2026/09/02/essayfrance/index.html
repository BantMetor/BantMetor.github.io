法语功能词占比的历时演变：词表法实测报告

2026-09-02

研究问题：法语从综合语向分析语演变的过程中，文本中功能词（虚词）占比是否显著上升？
方法：逐时期闭类词表（closed-class lexicon）计数，三个时期各 1200 词元语料 + 用户例句同流水线复测。
日期：2026-09-02 ｜ 可复现：node analyse_fonction_mots.js

0. 结论速览

  1. 假设的方向成立，但幅度比原先的估算小一个数量级：功能词占比（含助动词，口径 R_B）从 13 世纪的 53.8% 升到 20 世纪的 58.4%，1300 年间仅上升约 4.6 个百分点——不是”19% → 71%”的 52 个点。
  2. 原先三个例句的数字全部需要修正（详见 §3）：古法语片段 33.3%（原估 ~19%）、中古法语重构句 56.3%（原估 33–40%）、加缪句 74.1%（原估 ~71%，接近但词数口径有误）。
  3. 最有价值的发现不在总量，而在内部构成：中世纪文本的功能词重心是”衔接词”（介词+连词：古法语 22.8%、中古法语 30.3%），现代文本的重心转移到”指称词”（限定词+代词：30.8%）。分析化的微观机制发生了质变。
  4. 相应地，**实义词占比（词汇密度）**从 42.2% 降到 38.0%（口径 R_C 的补集）。

1. 方法与数据

1.1 语料（各 1200 词元，取正文起点之后）

时期 文本 成书 版本 来源
古法语 《Roman de la Rose》Guillaume de Lorris 部分 c. 1230 Marteau 1878 Project Gutenberg #16816
中古法语 Froissart《编年史》Livre I § 181（1342–1346） c. 1369–73 Luce 1869 学术版 Project Gutenberg #72385
现代法语 Proust《Du côté de chez Swann》Combray 开篇 1913 — Project Gutenberg #2650

为什么 Rose 而不是 Aucassin 做古法语语料：Project Gutenberg 无古法语散文；Aucassin 序诗（15 行）已从 3aroskear.co.uk 选集 核对原文，用作例句对照（§3），全文语料另用 Rose。此点及文体差异是本研究的主要局限（§5）。

1.2 计数方法：闭类词表，而非 POS 标注

现代 POS 标注器（spaCy 等）不识别 “del / vauroit / oïr / avés” 等历史形态，会系统性地把古法语功能词误判为名词。本研究采用逐时期功能词表：

  • 现代基底词表：约 600 词形（限定词、代词、介词、连词、否定词、助动词、边界副词）；
  • 中古增补：del dou du el es ou ès、li che chil chus（皮卡第形式）、avoit aroit vorroit、ot orent（avoir 简单过去时）、iert ert（être 将来时）等约 300 词形；
  • 古法增补：cist cil cele、ço çou、voil vuel viaus、vauroit 等；
  • 8 类词（det/pro/prep/conj/neg/aux/border/content），三个比率口径：
口径 定义
R_A （限定词+代词+介词+连词+否定词）/ N（最保守，不含任何动词）
R_B R_A + 助动词/半助动词（核心指标：avoir/être/pouvoir/devoir/vouloir/aller/venir/faire/laisser/falloir 的全部屈折形）
R_C R_B + 边界副词（程度/方式/时间副词、tout、même 等宽口径）

1.3 预处理与消歧规则（全部在脚本内可查）

  • 省音扩展：qu' → que、l' → le、jusqu' → jusque 等（补空格防止 qu'on → queon 词元合并）；
  • 剔除纯数字与罗马数字词元（保留 il/li/si/ci 等合法词）；
  • Luce 版清理：校勘行（[n] Mss./Ms. …）、行号、页码标记、异文标记 [qu'elle[248]] → qu'elle；
  • 歧义词按文体消歧：韵文样本中 vers = 名词（诗），散文样本中 = 介词；
  • 已知妥协：en/y 双类词按介词计、or（金/连词）、pas/point（步/否定）等歧义按功能词计——这类误差的方向在三时期一致，不影响历时对比的有效性。

2. 语料实测结果（主表）

N = 1200 词元/样本：

指标 古法语 13c（Rose） 中古法语 14c（Froissart） 现代法语 20c（Proust）
限定词 147 (12.3%) 141 (11.8%) 215 (17.9%)
代词 107 (8.9%) 55 (4.6%) 154 (12.8%)
介词 128 (10.7%) 209 (17.4%) 161 (13.4%)
连词 146 (12.2%) 155 (12.9%) 80 (6.7%)
否定词 24 (2.0%) 15 (1.3%) 18 (1.5%)
助动词 93 (7.8%) 78 (6.5%) 73 (6.1%)
边界副词 49 (4.1%) 40 (3.3%) 43 (3.6%)
实义词 506 (42.2%) 507 (42.3%) 456 (38.0%)
R_A 46.0% 47.9% 52.3%
R_B（核心） 53.8% 54.4% 58.4%
R_C（宽） 57.8% 57.8% 62.0%

2.1 总量：缓慢、单调、稳健的上升

  • R_B：53.8% → 54.4% → 58.4%（+4.6 点）；R_A：46.0% → 47.9% → 52.3%（+6.3 点）。
  • 该方向与”综合语→分析语”假设一致，也与既有文献的量级一致（法语书面散文功能词占比通常落在 50–60% 区间），而不是 19% 对 71%。
  • 古法语与中古法语的差距极小（53.8 vs 54.4），一个样本内不能解读为”无变化”——Rose 是韵文且为第一人称梦幻叙事（代词多、连词多），天然抬高古法语数值；需要古法语散文对照才能定论（§5）。

2.2 内部构成：分析化的机制变了（本研究最重要的发现）

功能词组 13c 14c 20c 趋势
限定词+代词（指称词） 21.2% 16.3% 30.8% 现代暴增
介词+连词（衔接词） 22.8% 30.3% 20.1% 中世纪高峰
  • 中世纪法语靠介词短语堆叠（Froissart 介词占 17.4%，”de le / à le / pour le” 尚未缩合）+ 大量 et / si / que 并列衔接；
  • 现代法语的语法负载转移到冠词系统和代词系统（Proust 限定词+代词合计 30.8%）：名词几乎不再”裸奔”，格位消失后由 de/à 前置词 + 冠词双重标记。
  • 这正是一个比”占比上升”更精确的分析化叙述：功能词总量小幅上升，但功能分工彻底重组——从”衔接”走向”指称与限定”。

3. 用户例句实测：逐条对照修正

同一流水线（同词表、同预处理）对四个例句的复测：

例句 原估算 实测 R_B 实测区间 问题所在
① 古法语片段（15 词） ~19% 33.3% 26.7–33.3% 漏算关系代词 qui；vers 在此是名词”诗”不是介词；vauroit 是 vouloir 条件式（情态助动词）；且 del/du 各是”介词+冠词”两个功能位，按词元计只有一个
①b 同段序诗全本（79 词） — 49.4% 40.5–54.4% 补上关系从句（qu'il soufri / qu'il fist）与续行后，功能词占比翻倍——证明 19% 是截断造成的假象
② 中古法语重构句（16 词） 33–40% 56.3% 50.0–56.3% 实有 9 个功能词（et, pour, ce, que, le, de, avoit, de, la）而非 5–6 个；漏了指示词 ce、冠词 la、助动词 avoit
③ 加缪《鼠疫》句 ~71% 74.1% 51.9–85.2% 原词数 24 有误：qu'on / l'on / l'être 拆开后为 27 词元；71% 本身落在合理区间，方向正确

3.1 方法论教训

  1. 单句没有统计效力：同一套流水线，四个例句的 R_B 在 33%–74% 之间波动。一个介词的增减 = 5–10 个点。≥1000 词元的语料才是可信的最小单位。
  2. 缩合形式要按功能位计：del = de + le。若把古法语的 del/du/es/ou 当一个词，会系统性低估古法语功能词占比——这恰好解释了你最初 19% 的来源：现代直觉 + 截断样本 + 单功能位计数三重偏差叠加。
  3. 助动词/系动词必须入表：avoit / est / puet / doit 是”分析语”的发动机——正是它们接替了屈折形态的语法功能，漏掉它们就测不到想要的东西。

4. 与”综合语→分析语”理论的关系

  • 本数据支持该理论的一个弱版本：功能词占比缓慢上升（+4.6 点/R_B），实义词密度缓慢下降（42.2% → 38.0%）；
  • 但不支持”虚词占比从 19% 暴涨到 71%”的强叙事。综合→分析的转变在13 世纪之前（拉丁语晚期→古法语早期，格位消失时）就已基本完成；13–20 世纪观察到的是分析化在内部的持续深化与重组（冠词强制化、代词膨胀、介词语法化），而非从零开始。
  • 若想测到”剧变”，正确的时间窗口应上推至 9–12 世纪（《斯特拉斯堡誓言》842 / 《圣阿莱克西行传》11c / 《罗兰之歌》c. 1100），或把粒度放到”每名词的冠词覆盖率””屈折残存率”等更细的指标。

5. 局限与下一步

  1. 文体混杂：Rose 是韵文（第一人称梦幻叙事），Froissart/Proust 是散文。古法语数值可能被文体抬高。应加入古法语散文对照：Villehardouin《君士坦丁堡征服记》（1207–13，Wikisource/Gallica 有全文，需 HTTPS 环境下载）。
  2. 单点取样：每时期 1 个文本 1 段。下一步每时期取 3–5 个文本 × 多段样本，做 bootstrap 置信区间与显著性检验（脚本已模块化，扩展即可）。
  3. 版权提示：加缪《鼠疫》（1947）在法国受版权保护至 2031 年；本报告仅对单句作统计引用。正式论文建议改用 Proust（1922 年去世，公有领域）或 Gide 等。
  4. 词表完备性：OF/MF 词表覆盖高频功能词形，但冷僻变体（如 amprès / tresque 等）可能有漏网；建议后续用古法语词典（Godefroy/TLFi 词源栏）系统核对。
